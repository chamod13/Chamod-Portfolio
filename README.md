## 🚀 Live Demo & Hosting on GitHub Pages

This portfolio is **100% static** (zero frameworks, zero build steps, zero dependencies). You can host it directly on **GitHub Pages** for free.

### Step-by-Step Instructions to Host:

1. **Create a GitHub Repository**:
   - Go to [github.com/new](https://github.com/new).
   - Repository name: `Portfolio` (or `chamod13.github.io` for a root user domain).
   - Set visibility to **Public**.
   - Click **Create repository**.

2. **Upload / Push the Files**:
   - Push or upload all files from this directory to the repository:
     - `index.html`
     - `style.css`
     - `script.js`
     - `profile.jpg`
     - `README.md`

   *Using Git Terminal*:
   ```bash
   git init
   git add .
   git commit -m "Initial commit - DCS Jayawickrama Portfolio"
   git branch -M main
   git remote add origin https://github.com/chamod13/Portfolio.git
   git push -u origin main
   ```

3. **Activate GitHub Pages**:
   - Open your repository on GitHub.
   - Click **Settings** ➔ **Pages** (in the left sidebar).
   - Under **Build and deployment**:
     - Source: `Deploy from a branch`
     - Branch: `main` / `root`
   - Click **Save**.
   - Your site will be live within 1–2 minutes at:  
     `https://chamod13.github.io/Portfolio/`
